# 四季小探險家 3D (P2 Four Seasons Explorer)

專為**香港小學二年級學生**以 **iPad** 遊玩而設計的 **Nintendo Switch 級別 3D 四季科學探索網頁遊戲**。

## ✨ 核心特色

1. **🎨 Switch 級別立體山河微縮景觀（Blender Principled BSDF PBR + IBL）**
   - 採用 `PMREMGenerator` 即時環境光反射與 `MeshPhysicalMaterial` 清漆材質，塑造**巍峨高山、蜿蜒清澈河流、4 座木製拱橋**及 5 大季節科學地標。
2. **📐 精確地形、拱橋與河流物理引擎（SI 國際單位制）**
   - 統一地形高度場與法線坡度計算（陡峭山壁自動滑落阻擋、上下斜坡具真實重力分量、木拱橋無縫銜接兩岸並設護欄防墜、涉水過河具流體阻力與水花漣漪）。
3. **🗺️ 右上方半透明即時虛擬地圖（Retina Minimap）**
   - 即時顯示四大季節分區、河流走向、4 座小橋、高山位置、5 座地標建築、發光任務寶石、百厭小猴子動態及玩家視角扇區。
4. **🧒 高對比鮮明細緻主角與 3D 手提物品**
   - 深色立體髮型、靈動五官、雙色運動鞋、立體探險背囊，並支援隨天氣切換**防風雨衣、羽絨大衣、圍巾、冷帽、遮陽闊邊帽**及 **6 款 3D 手提物品**（雨傘、發光防霧電筒、冰涼小風扇、生態放大鏡、觀鳥望遠鏡、保溫暖水壺、溫暖營燈）。
5. **⛈️ 動態四季天氣變化＋音效文字提醒＋應變選擇題**
   - 春、夏、秋、冬各有 3 種動態天氣（如夏季晴天、驟雨、狂風暴雨等）；天氣轉變時發出逼真環境音效與文字提示，並彈出應變選擇題（支援**廣東話讀出問題及全部選項**），答對即場換裝及更換手提物品，答錯則耐心講解後讓學生重選。
