# 四季小探險家 3D (P2 Four Seasons Explorer)

專為**香港小學二年級學生**以 **iPad** 遊玩而設計的 **Nintendo Switch 級別 3D 香港四季生態探索遊戲**。

## ✨ 核心特色

1. **🏅 畫面中央上方「寶可夢道館級」四季大獎章盒**
   - 設有專屬向量金屬圖騰：**春・紫荊徽章**、**夏・綠龜徽章**、**秋・琵鷺徽章**、**冬・穿山甲徽章**。
   - **完整闖關流程**：每季各有 **2 個固定任務點**（河畔平原 ① ＋ 山頂觀景台 ②）收集小徽章；完成該季 2 個任務點後，**3D 金色導航箭嘴**會自動亮起，引導學生前往該季**香港特色動植物**互動，贏取該季大獎章！集齊 4 枚大獎章即可獲發榮譽證書。
2. **🌺 香港特色動植物 3D 生態互動**
   - 四大守護物種：**香港市花洋紫荊與鳳蝶**、**南丫島深灣綠海龜**、**米埔濕地黑臉琵鷺**、**中華穿山甲**。
   - 八大本土生態點：**盧氏小樹蛙**、**香港吊鐘花**、**中華白海豚**、**招潮蟹**、**大欖楓香樹**、**大東山芒草**、**紅耳鵯**、**香港茶（山茶花）**。
3. **🏔️ 可自由攀登的四季高山、清澈河流與木拱橋**
   - 全島高山經過坡度與物理校準，主角可沿登山石階直登四季山頂俯瞰全島，並設廣角遠景鏡頭讓地圖視野更開闊。
4. **🧥 深色高對比主角與舒適節奏天氣換裝**
   - 主角採用深邃髮色、暖古銅膚色與深海軍藍／深森綠／深酒紅等高辨識度服裝；天氣變化延長至舒適節奏，答對天氣題即場更換衣著與 3D 手提物品（不計入獎章）。
